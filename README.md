# Multiband Sample Delay by XS

**Multiband Sample Delay by XS** is a free multiband stereo processing plugin designed for precise timing control, stereo widening and rhythmic enhancement.

By processing different frequency ranges independently, it allows you to create width, movement and additional rhythmic detail without applying the same delay to the entire frequency spectrum.

It works especially well on **drums, percussion, leads, synths and buses**, and can also be used creatively on **finished tracks and full mixes**.

## Features

* Multiband sample delay processing
* Precise delay control in individual samples
* Independent processing of different frequency ranges
* Independent stereo Left / Right timing control
* Create stereo width without delaying the entire signal
* Add rhythmic movement and spatial depth
* Useful for phase and timing adjustment
* Smooth parameter transitions with **10 ms crossfade** to reduce clicks and artifacts
* Designed for real-time audio processing
* Suitable for individual instruments, buses and complete mixes

## What Can It Be Used For?

### Stereo Widening

Create frequency-dependent stereo width by applying small timing differences between the Left and Right channels.

Unlike a traditional full-band sample delay, multiband processing allows you to control which parts of the frequency spectrum become wider.

### Rhythmic Enhancement

Small delays can introduce additional movement and rhythmic detail to drums, percussion, synths and other material.

### Frequency-Dependent Timing

Adjust the timing of different frequency ranges independently instead of shifting the entire signal.

This can be useful for creative processing, stereo manipulation and phase-related adjustments.

### Finished Tracks

Multiband Sample Delay by XS can also be used on buses, stereo mixes and finished tracks when subtle frequency-dependent stereo processing is required.

## Installation

### Windows — VST3

Copy:

`Multiband Sample Delay by XS.vst3`

to:

`C:\Program Files\Common Files\VST3\`

Then restart your DAW or rescan your plugins.

### Windows — CLAP

If a CLAP version is included in the current release, copy:

`Multiband Sample Delay by XS.clap`

to:

`C:\Program Files\Common Files\CLAP\`

Then restart your DAW or rescan your plugins.

### macOS — VST3

Copy the VST3 plugin to:

`/Library/Audio/Plug-Ins/VST3/`

### macOS — Audio Unit

Copy the Audio Unit plugin to:

`/Library/Audio/Plug-Ins/Components/`

### macOS — CLAP

Copy the CLAP plugin to:

`/Library/Audio/Plug-Ins/CLAP/`

Restart your DAW after installation.
